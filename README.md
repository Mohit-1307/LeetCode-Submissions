# Overview

This repository serves as a personal archive of my Data Structures and Algorithms (DSA) journey on **LeetCode**. Every accepted solution is automatically synchronized to GitHub using **LeetHub v2**, making it easy to track progress, revisit previous solutions, and maintain a version-controlled coding portfolio.

---

# Repository Structure

Solutions are organized by topic and problem directory. Multiple accepted submissions for the same problem are preserved as separate versions.

```text
<topic>/
  <problem-slug>/
    submission-0.<ext>
    submission-1.<ext>
    ...
```

### Example

```text
arrays/two-sum/submission-0.py
binary-search/search-in-rotated-array/submission-0.py
dynamic-programming/climbing-stairs/submission-0.py
```

# Automatic Sync Workflow

This repository is powered by **LeetHub v2**, which automatically synchronizes accepted LeetCode submissions with GitHub.

```text
Solve a problem on LeetCode
            │
            ▼
LeetHub v2 detects the accepted submission
            │
            ▼
Repository is updated automatically
            │
            ▼
Git commit is created with the latest solution
```

### One-Time Setup

1. Install **LeetHub v2** in your browser.
2. Authorize your GitHub account.
3. Sign in to LeetCode if prompted.
4. Select this repository for synchronization.
5. Start solving problems—accepted submissions are automatically pushed to GitHub.
